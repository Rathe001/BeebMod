# The five new Forever dungeons from level 35 up · not written yet

These have no notes in Data.lua. Warcraft Tavern's guides say they are built
on "preliminary information from Blizzard and datamining" and that nobody has
seen inside yet. The Warcraft Wiki has no boss pages for them, and Method has
no guide (HTTP 404). Read 2026-11-07.

| Dungeon | Levels (W) | Bosses known (W) |
|---|---|---|
| The Drowned City | 35-42 | Zul'Alai, Zin'aka, Var'Taka, Captain Dreadrise (from the BlizzCon demo; "there are likely more"). The two lists on the page disagree on whether Var'Taka or Zin'aka comes second. |
| Krol'dok Stronghold | 40-47 | Overlord Mugg (from the dungeon's Legacy challenge) |
| Alcaz Island Prison | 48-55 | Blazeroar (from the Legacy challenge) |
| Blackmaw Hold | 55-60 | Varrox Bleakhoof (from the Legacy challenge) |
| Shaper's Terrace | 58-60 | Bolt, Cinder, Snowtalon, Nanaya (from Legacy challenges; "there are likely more") |

No source gives an ability, an order or an npc id for any of them. Two ways
to fill them in: a guide once one is written, or the Testing page's Dungeon
run record, which writes down each fight's name as the game sends it.

In a run, the quest tracker still narrows to the dungeon's own quests. The
Encounter section stays away until there are notes.
