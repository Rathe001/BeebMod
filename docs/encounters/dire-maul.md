## Notes and disagreements

- Each wing names its instance `diremaul`. The game may call every wing Dire Maul, so the wing is the one whose boss is fought. East shows until then.
- W's overview and wing guides order East and West differently. The wing guides' order is used.
- North's guards are optional: a tribute run leaves them alive. King Gordok and Cho'Rush are one entry.
- **Left out:** Tsu'zee (rare), Isalien (Tier 0.5 quest), Lord Hel'nurath (warlock mount quest).
